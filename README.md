# LED-BLINK-USING-ARDUINO
# Arduino LED Blinking Project 💡

## 📌 Description
This project demonstrates a basic LED blinking circuit using an Arduino board. The LED turns ON and OFF at regular time intervals, controlled by a simple Arduino program written in C/C++.

It is a beginner-friendly electronics project that helps understand Arduino programming, digital output pins, and time delays.

## 🛠️ Components Required
- Arduino Uno
- LED
- 220Ω resistor
- Breadboard
- Jumper wires
- USB cable

## ⚡ Working Principle
The Arduino sets a digital pin as an output and alternates its state between HIGH and LOW. The LED turns ON when the pin is HIGH and OFF when the pin is LOW, with a delay between each state.

## 💻 Technologies Used
- Arduino
- Embedded C/C++
- Arduino IDE

## 🚀 How to Run
1. Connect the LED to the Arduino through a 220Ω resistor.
2. Connect the LED's cathode to GND.
3. Open the Arduino IDE.
4. Upload the LED blinking program to the Arduino board.
5. Observe the LED blinking at regular intervals

## 🎯 Learning Outcomes
- Understanding Arduino digital output pins.
- Learning basic Arduino programming.
- Using the `pinMode()`, `digitalWrite()`, and `delay()` functions.
- Building a simple hardware circuit.

## 📷 Project Output
The LED continuously turns ON and OFF at regular intervals.
